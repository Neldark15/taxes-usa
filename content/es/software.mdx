# Software y herramientas profesionales

Tu stack tecnológico determina tu productividad y compliance. No uses TurboTax o software de consumidor — usa software profesional.

## Software de preparación de impuestos

### Tier A — Enterprise/Large Firms

- **UltraTax CS** (Thomson Reuters) — $2,500+/año, para firmas grandes
- **Lacerte** (Intuit) — $3,000+/año, complejo, multi-state avanzado
- **ProSystem fx Tax** (Wolters Kluwer) — similar tier

### Tier B — Independientes y pequeñas firmas ⭐

- **Drake Tax** — $1,795/año unlimited, muy popular entre independientes, solid VA support
- **TaxSlayer Pro** — $1,195/año, buen value, interfaz moderna
- **ProSeries** (Intuit) — $1,500+/año, familiar para quienes vienen de TurboTax
- **ATX** (CCH) — similar a Drake

### Tier C — Entry level

- **TaxAct Professional** — $750/año, básico pero funcional
- **CrossLink** — popular con service bureaus

### Tier D — Cloud-based nuevos

- **TaxDome + integrations** (no hace taxes, es gestión)
- **Canopy** — cloud tax software emergente

### Recomendación para arrancar

**Drake Tax** es la opción más popular entre preparadores independientes de la diáspora:

- Precio razonable
- Soporte de VA bueno
- Integra Schedule C/SE/EIC/ITIN bien
- Mucha comunidad hispanohablante
- Training gratuito

Costo primer año con nuevo cliente: $1,200-1,500 (discount primer año).

<Callout type="warning" title="EFIN requirement">
Todo software profesional requiere que ingreses tu EFIN para e-file. Si no tienes EFIN (ver cap. 06), tienes que trabajar con un ERO partner o presentar en papel.
</Callout>

## Gestión de práctica (Practice Management)

### TaxDome ⭐ RECOMENDADO

$50-80/mes. Incluye:

- Portal seguro del cliente
- CRM
- E-signature integrada (para 8879)
- Document management
- Billing e invoicing
- Workflow automation
- Client messaging

Es el estándar emergente para preparadores modernos. La curva de aprendizaje es considerable pero vale la pena.

### Alternativas

- **Canopy** — similar a TaxDome, más caro
- **Karbon** — más orientado a accountants
- **Liscio** — portal simple + messaging
- **SmartVault** — solo document storage ($40/mes)

## Firma electrónica (E-signature)

Para el Form 8879 (authorización e-file) el cliente DEBE firmar electrónicamente:

- **DocuSign** — estándar corporativo, $25/mes
- **Adobe Sign** — similar, integrado con Acrobat
- **signNow** — más barato
- **TaxDome** — ya incluye si usas TaxDome
- **Drake Document Management** incluye e-sign

## Portal seguro para documentos del cliente

**NUNCA uses email sin encriptar** para W-2s, 1099s, passports, SSN, etc.

- **TaxDome** (incluye)
- **SmartVault**
- **ShareFile** (Citrix)
- **Box / Google Drive con 2FA** — mínimo aceptable si no puedes costear otro

## Comunicación con clientes

- **Email encriptado**: ProtonMail, Virtru, Tutanota
- **WhatsApp Business**: MUY popular en comunidad diáspora, útil para awareness pero NO para compartir documentos
- **Slack / Discord**: si manejas grupos de clientes

## Contabilidad propia (tu negocio)

- **QuickBooks Self-Employed** — $15/mes, simple
- **Wave** — gratis, suficiente para empezar
- **FreshBooks** — $15/mes
- **Xero** — $13/mes, bueno para multi-currency

## Research y referencia fiscal

- **The Tax Book** — $85/año, referencia concisa (muy popular)
- **CCH AnswerConnect** — $500+/año, extenso
- **Checkpoint** (Thomson Reuters) — enterprise
- **IRS.gov** — gratis, Publications, Form instructions (autoridad final)
- **TaxPro Today** / **Accounting Today** — revistas online gratis

## Security must-haves

### Obligatorio bajo IRS Pub 4557 y FTC Safeguards Rule

- **Password manager** — 1Password, Bitwarden ($3/mes)
- **2FA en todo** — Authy, Google Authenticator
- **Antivirus profesional** — Bitdefender, Malwarebytes
- **VPN** — NordVPN, ExpressVPN (especialmente en WiFi público)
- **Disk encryption** — BitLocker (Windows) o FileVault (Mac)
- **Backup encriptado** — Backblaze ($9/mes), Carbonite
- **Firewall** activado
- **Updates automáticos** de OS

### WISP — Written Information Security Plan

**OBLIGATORIO** por IRS/FTC. Es un documento que describe cómo proteges los datos de los clientes:

- Plantillas gratis en NATP, NAEA
- El IRS tiene un sample WISP en Publication 5708
- Debes revisarlo anualmente
- Lo pueden pedir en audit

## Herramientas adicionales

### Accounting software para recibir pagos

### Automatización

- **Zapier / Make** — conectar TaxDome con otras apps
- **Calendly** — scheduling de clientes
- **Loom** — video mensajes explicativos
