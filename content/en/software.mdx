# Professional Software and Tools

Your tech stack determines your productivity and compliance. Don't use TurboTax or consumer software — use professional software.

## Tax preparation software

### Tier A — Enterprise/Large Firms

- **UltraTax CS** (Thomson Reuters) — $2,500+/year, for large firms
- **Lacerte** (Intuit) — $3,000+/year, complex, advanced multi-state
- **ProSystem fx Tax** (Wolters Kluwer) — similar tier

### Tier B — Independents and small firms ⭐

- **Drake Tax** — $1,795/year unlimited, very popular among independents, solid VA support
- **TaxSlayer Pro** — $1,195/year, good value, modern interface
- **ProSeries** (Intuit) — $1,500+/year, familiar to TurboTax migrants
- **ATX** (CCH) — similar to Drake

### Tier C — Entry level

- **TaxAct Professional** — $750/year, basic but functional
- **CrossLink** — popular with service bureaus

### Tier D — New cloud-based

- **TaxDome + integrations** (doesn't do taxes, practice management)
- **Canopy** — emerging cloud tax software

### Starter recommendation

**Drake Tax** is the most popular option among independent diaspora preparers:

- Reasonable price
- Good VA support
- Integrates Schedule C/SE/EIC/ITIN well
- Large Spanish-speaking community
- Free training

First-year cost with new-customer discount: $1,200-1,500.

<Callout type="warning" title="EFIN requirement">
All professional software requires you to enter your EFIN to e-file. If you don't have an EFIN (see ch. 06), you need to work with an ERO partner or file on paper.
</Callout>

## Practice Management

### TaxDome ⭐ RECOMMENDED

$50-80/month. Includes:

- Secure client portal
- CRM
- Built-in e-signature (for 8879)
- Document management
- Billing and invoicing
- Workflow automation
- Client messaging

Emerging standard for modern preparers. Considerable learning curve but worth it.

### Alternatives

- **Canopy** — similar to TaxDome, more expensive
- **Karbon** — more oriented to accountants
- **Liscio** — simple portal + messaging
- **SmartVault** — document storage only ($40/month)

## E-signature

For Form 8879 (e-file authorization) the client MUST sign electronically:

- **DocuSign** — corporate standard, $25/month
- **Adobe Sign** — similar, integrated with Acrobat
- **signNow** — cheaper
- **TaxDome** — already included if using TaxDome
- **Drake Document Management** includes e-sign

## Secure client document portal

**NEVER use unencrypted email** for W-2s, 1099s, passports, SSN, etc.

- **TaxDome** (included)
- **SmartVault**
- **ShareFile** (Citrix)
- **Box / Google Drive with 2FA** — minimum acceptable if you can't afford other options

## Client communication

- **Encrypted email**: ProtonMail, Virtru, Tutanota
- **WhatsApp Business**: VERY popular in diaspora community, useful for awareness but NOT for sharing documents
- **Slack / Discord**: if you manage client groups

## Security must-haves

### Mandatory under IRS Pub 4557 and FTC Safeguards Rule

- **Password manager** — 1Password, Bitwarden ($3/month)
- **2FA on everything** — Authy, Google Authenticator
- **Professional antivirus** — Bitdefender, Malwarebytes
- **VPN** — NordVPN, ExpressVPN (especially on public WiFi)
- **Disk encryption** — BitLocker (Windows) or FileVault (Mac)
- **Encrypted backup** — Backblaze ($9/month), Carbonite
- **Firewall** enabled
- **Automatic OS updates**

### WISP — Written Information Security Plan

**MANDATORY** per IRS/FTC. A document describing how you protect client data:

- Free templates at NATP, NAEA
- IRS has sample WISP in Publication 5708
- Must review annually
- Can be requested in audit
